About Pigmentary

Pigmentary collects AI-generated SVG color palettes into a side-by-side strip stream so you can preview color balance fast, grab raw vector files, copy hex codes one line per color, and extract prompt text embedded inside SVG classes or IDs.

Create new palettes in the Gemini palette app , download the SVG, and upload it here.
